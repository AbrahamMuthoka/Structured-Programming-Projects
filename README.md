# Structured Programming Projects

This repository contains projects developed for the Structured Programming class using the C programming language. The projects are designed to apply programming concepts to practical applications while developing problem solving, logical thinking, and software development skills.

## About the Repository

The Structured-Programming-Projects repository contains a series of C programming projects developed throughout the course. Each project introduces different programming concepts and provides an opportunity to apply those concepts in a practical setting.

The projects focus on:

* Variables and data types
* Arithmetic and logical operations
* Conditional statements
* Loops and iteration
* Functions
* Arrays and data structures
* Input validation
* File handling
* Data management
* Program organization
* Problem solving

## Projects

### Project 1: Simple Calculator

The Simple Calculator is a basic C program designed to perform common arithmetic operations.

The calculator allows users to enter numerical values and select an operation to perform.

Supported operations include:

* Addition
* Subtraction
* Multiplication
* Division

This project focuses on fundamental C programming concepts, including variables, data types, operators, user input, output, and conditional statements.

### Project 2: Freelance Tycoon

Freelance Tycoon is a C based desktop GUI app that manages freelance work and projects.

The app allows the userr to manage clients, projects, earnings, losses, and project progress. Users can monitor their freelance activities and make decisions that affect their overall performance.

The app includes features such as:

* Client management
* Project management
* Earnings tracking
* Loss tracking
* Pending projects
* Completed projects
* Project status monitoring
* Financial tracking
* Work progress
* Player performance

The goal of Freelance Tycoon is to combine structured programming concepts with an interactive scenario that represents the challenges of managing freelance work.

## Learning Objectives

These projects are intended to provide practical experience with the concepts covered in Structured Programming.
