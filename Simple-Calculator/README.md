# Simple Calculator

A simple calculator application developed in C as the first project for the Structured Programming class.

## Overview

The Simple Calculator performs basic arithmetic operations based on values entered by the user. The project introduces fundamental C programming concepts and provides a practical application of variables, operators, user input, and program control structures.

## Features

The calculator supports the following operations:

* Addition
* Subtraction
* Multiplication
* Division

The application accepts numerical input from the user, performs the selected operation, and displays the calculated result.

## Programming Concepts

This project demonstrates the use of:

* Variables
* Data types
* Arithmetic operators
* User input and output
* Conditional statements
* Functions
* Basic input validation
* Program control flow

## Technologies

* Programming language: C
* Application type: Calculator application
* Development environment: To be specified

## How It Works

1. The user starts the calculator.
2. The user enters the required numerical values.
3. The user selects an arithmetic operation.
4. The program performs the selected calculation.
5. The calculated result is displayed.
6. The user can perform another calculation or exit the application.

## Purpose

The purpose of this project is to develop a basic understanding of structured programming using C. It provides a foundation for working with input, processing, output, functions, and decision making.
