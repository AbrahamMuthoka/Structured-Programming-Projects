# Freelance Tycoon

Freelance Tycoon is a desktop GUI application developed in C as the second project for the Structured Programming class.

## Overview

Freelance Tycoon is designed to help users manage and monitor their freelance work through a graphical desktop interface. The application provides a centralized system for organizing clients, projects, earnings, losses, and project progress.

The application is designed around the workflow of a freelancer who needs to keep track of multiple projects and maintain an overview of their professional activities.

## Features

### Client Management

The application allows users to maintain information about their clients and associate clients with their respective projects.

Client information may include:

* Client name
* Contact information
* Project details
* Client status
* Additional notes

### Project Management

Users can create and manage freelance projects while monitoring their progress.

Project management includes:

* Project name
* Client information
* Project description
* Project status
* Start date
* Deadline
* Project value
* Project progress

### Earnings Tracking

The application allows users to monitor income generated through freelance projects.

Users can record project earnings and review their financial activity based on completed and ongoing work.

### Loss Tracking

Freelance Tycoon also provides a way to record financial losses and project related expenses.

This allows users to maintain a broader view of their freelance finances rather than tracking income alone.

### Project Status

Projects can be monitored according to their current status.

Possible project statuses include:

* Pending
* In progress
* Completed
* Cancelled

This allows users to distinguish between unfinished and completed work.

### Dashboard

The application provides an overview of important freelance information, allowing users to monitor their projects and financial activity from one location.

The dashboard can provide information such as:

* Total projects
* Pending projects
* Completed projects
* Total earnings
* Total losses
* Overall financial balance

## Application Workflow

The general workflow of the application is:

1. Launch the application.
2. Access the main dashboard.
3. Add or manage client information.
4. Create and manage projects.
5. Update project statuses as work progresses.
6. Record project earnings and losses.
7. Review project and financial information.
8. Update records when project circumstances change.

## Purpose

The purpose of Freelance Tycoon is to apply structured programming concepts to a practical desktop application.

The project extends the concepts introduced in the Simple Calculator by requiring more complex data management, program organization, user interaction, and application functionality.
